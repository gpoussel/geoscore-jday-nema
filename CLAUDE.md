# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Context

Astro 6 static site rendering a GeoGuessr Duels stats dashboard for the JDay × Néma duo. This directory is the git root. The Python data pipeline lives alongside in `stats/` and is tracked in the same repo.

## Commands

```bash
pnpm install
pnpm run dev        # http://localhost:4321
pnpm run build      # astro check && astro build — the only correctness gate
pnpm run preview    # serve dist/
```

There is no test suite. `astro check` (run as part of `build`) must stay at 0 errors/warnings.

## Data inputs

- `src/data/stats.json` — generated by `stats/build_stats.py` from `stats/games.csv` + `stats/sessions.json`. Regenerate via `cd stats && uv run build_stats.py`. Don't edit by hand.
- `src/data/players.json` — hand-maintained source of truth for player identity (names, Twitch/YouTube/GeoGuessr). Never regenerate from Python.
- `src/data/world.ts` — simplified world map: one `<rect>` per country on a 1000×500 viewbox. Used by `BlockPays.astro`.

Session IDs follow `week.num` format (`1.5` = week 1, session 5).

## Architecture

Fully static Astro, **no React, no client framework**. A previous version had `@astrojs/react` — it was removed; don't add client frameworks back without explicit reason. Chart.js is loaded as a vanilla lib via Astro `<script>` (bundled, tree-shaken), not a framework.

- **Dual-period render, not runtime state.** `src/pages/index.astro` computes both `week1` and `all` view datasets at build time and emits two `<div data-view="…">` trees with identical block structure. `PeriodToggle.astro` flips `body.period-week1` / `body.period-all` via inline script; `is:global` CSS rules in `index.astro` hide the inactive view. No hydration. The hidden view starts at `display:none` so charts init with 0 size — `BlockElo.astro` re-`resize()`s its Chart.js instances on period-button clicks.
- **Charts.** ELO line chart (`BlockElo.astro`) uses Chart.js with a canvas, JSON data embedded via `<script type="application/json" is:inline>`, and an external HTML tooltip (`.elo-tooltip`) for full theming. A small custom plugin draws `HIGH`/`LOW` labels on peak/trough points. Donut + margin bars stay hand-SVG/CSS.
- **World map tooltip** = small inline script in `BlockPays.astro` reading `data-*` attributes off country rects. Keep tiny indicators zero-JS; prefer Chart.js for new data-driven charts.
- **Reusable primitives live in `src/components/ui/`** (`Kpi`, `Card`, `CardHead`, `BlockHead`, `Social`, `TeamMember`, `RankBadge`). Blocks in `src/components/` compose these primitives.

## Styling conventions

- **Component styles are scoped** to their `.astro` `<style>` block. `src/styles/global.css` holds only design tokens, the body gradient + noise overlay, and `.app` / `.header` / `.footer` chrome. Don't move component CSS there.
- Colors are OKLCH. Hue 285 = purple/indigo base, 172 = teal (win), 50 = orange (loss). Keep new colors in-palette via `color-mix(in oklch, …)` when interpolating (see `BlockPays.astro`).
- Typography: `--serif` Instrument Serif italic for display numbers, `--sans` Geist for UI, `--mono` JetBrains Mono for metric values. Section labels are sans uppercase with letter-spacing.
- Density tokens: `--pad: 32px`, `--gap: 24px`, `--radius: 14px`.
